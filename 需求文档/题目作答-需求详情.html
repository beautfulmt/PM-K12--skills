题目作答模块 — 需求详情

所属产品：微信小程序  |  模块类型：子模块  |  版本：V1.0

一、作答流程图

二、详细方案

一级模块 二级功能 原型 描述
答题通用 题组加载

0、功能说明

  • 题目以"组"为单位下发，进入答题页时一次性拉取整组题目数据
  • 一组题可混合多种题型（口算/选择/朗读）

1、页面通用元素

  • 顶部导航：左侧关闭按钮（X） + 中间题型标签（蓝/橙/绿色区分）
  • 进度条：显示"第 N/M 题" + 百分比 + 渐变色进度条
  • 底部操作：上一题（灰色）+ 下一题/提交（主色）

2、导航规则

  • 第一题时"上一题"按钮置灰不可点
  • 最后一题按钮文案改为"提交"
  • 支持前后翻页，可修改已答题目
退出确认

0、功能说明

  • 点击左上角 X 时弹出确认弹窗

1、弹窗内容

  • 标题："确定退出练习吗？"
  • 描述："退出后本次作答记录不会保存"
  • 按钮："继续答题"（主色）/ "退出"（灰色）
数学-口算题 手写作答

0、功能说明

  • 学生在Canvas手写区用手指书写数字答案

1、题目区

  • 居中大字号展示算式，未作答部分显示蓝色"?"占位
  • 题目类型：加减乘除，一位数到三位数运算

2、手写区

  • Canvas画布区域，带虚线边框和浅灰辅助网格
  • 右上角"清除"按钮，点击清空画布内容
  • 笔迹粗细：3px，颜色：深灰 #374151
  • 支持多笔画书写，每次落笔即追加

3、识别规则

  • 点击"下一题"时触发本地手写识别，将笔迹转为数字
  • 识别结果暂存本地，不立即判对错
  • 若无法识别，提示"请重新书写，确保数字清晰"
识别失败兜底

0、触发条件

  • 手写内容无法被识别为有效数字（乱画/过于潦草）

1、处理方式

  • 底部弹出轻提示toast："字迹不太清楚，请重新书写哦"
  • 不自动清除画布，学生可手动清除后重写
  • 连续3次识别失败，弹出数字键盘输入兜底
语文-选择题 选项作答

0、功能说明

  • 标准单选题，点击选项即选中

1、题目区

  • 题干文字黑色正文展示，支持富文本（加粗/下划线标注考查字词）

2、选项区

  • 每个选项为卡片式布局：圆形字母标记（A/B/C/D）+ 选项内容
  • 未选中：白色背景 + 浅灰边框，字母圆圈灰色
  • 选中：浅蓝背景 + 蓝色粗边框 + 字母圆圈变蓝底白字 + 右上角蓝色勾
  • 点击另一选项切换选中态（单选）

3、交互规则

  • 未选择答案时点击"下一题"，弹出toast："请先选择一个答案"
  • 已选答案暂存本地，返回该题时恢复选中状态
语音朗读题 待录音态

0、功能说明

  • 展示待朗读文本，学生需朗读后由AI评分

1、朗读内容区

  • 黄底卡片展示朗读文本，大字号、宽行距便于阅读
  • 可展示拼音标注（针对低年级）
  • 底部显示出处（作者/来源）

2、示范朗读

  • 提供"听示范朗读"播放器，学生可先听一遍标准发音
  • 播放器含：播放按钮 + 进度条 + 时长

3、录音入口

  • 底部居中大圆按钮（绿色麦克风图标）
  • 提示文案："点击下方按钮开始录音 / 请在安静环境下录音"
录音中态

0、状态变化

  • 点击录音按钮后进入录音中状态

1、页面展示

  • 波形动画：7根竖条随声音振幅动态跳动
  • 录音计时器：显示"录音中... 00:XX"
  • 提示："请大声、清晰地朗读"

2、底部操作

  • 中央：红色停止按钮（由绿色录音切换而来）
  • 左侧：重录按钮（清除当前录音重新开始）
  • 右侧：下一题按钮（录音中时置灰不可点）

3、录音规则

  • 最长录音时间：60秒，到时自动停止
  • 最短有效时长：2秒，不足则提示"录音太短了"
  • 静音检测：连续5秒无声音输入，自动停止并提示
录音完成

0、状态变化

  • 点击停止 / 自动到时停止后进入此状态

1、页面展示

  • 波形静止，显示"录音完成 ✅"
  • 可点击回放按钮试听自己的录音

2、操作

  • "重录"：清除本次录音，回到待录音态
  • "下一题"：可用，暂存音频到本地
练习报告 结果汇总

0、功能说明

  • 全部题目提交后，显示练习报告汇总页

1、成绩卡片

  • 圆形大字号总分（百分制）
  • 评语标签（根据分数段）：≥90 "太棒了🌟" / ≥70 "不错哦👍" / ≥60 "继续加油💪" / <60 "再接再厉📚"
  • 四项统计：答对数 / 答错数 / 总题数 / 用时

2、答题明细列表

  • 逐题展示：题号 + 题型标签 + 题目摘要 + 对错状态
  • 正确：绿色勾 + "正确"
  • 错误：红色叉 + "错误"，整行浅红底色
  • 朗读题：显示AI评分（如"92分"），而非简单对错
  • 点击错题行可跳转错题详情页

3、底部操作

  • "查看错题"：跳转错题集页面
  • "完成"：返回上级页面

4、数据上报

  • 提交后服务端保存本次练习记录
  • 语音朗读的音频文件上传后由AI异步评分
错题详情

0、功能说明

  • 从结果页点击错题进入，展示该题的详细对比

1、页面内容

  • 原题展示 + 题型标签 + 错误标记
  • 并排对比：学生答案（红色）vs 正确答案（绿色）
  • 提示卡片（黄底）：解释错误原因或学习提示

2、操作

  • "下一道错题"：翻到下一道错题
  • 最后一道错题时按钮变为"返回报告"
⚠️ 评分规则：口算题和选择题由服务端直接判分（对/错）；语音朗读题上传音频后由AI评分服务异步打分（0-100分），朗读评分≥60分视为"通过"。
