## 一致性要求

1. 页面文案、示例数据、状态名称和按钮文字与 PRD、HTML 原型逐条一致。
2. 页面顺序和跳转关系与交互流程图一致。
3. 同类组件使用统一尺寸、圆角、描边、图标和状态样式。
4. 文字、按钮、输入框和动态数据保持为可编辑 UI 元素，不烘焙进图片。
5. 品牌 Logo、真实产品图、人物照片和专属插画优先使用用户提供的原始资产。
6. 复杂图片缺失时使用明确占位，并在交付说明中列出待补资产。
7. 所有明显可交互元素都要提供默认、悬停、按下、禁用或选中状态中实际需要的部分。

## 绘制与验证

1. 先调用 `get_editor_state` 获取当前画布状态。
2. 调用 `get_guidelines` 加载可用设计指南。
3. 使用 `set_variables` 建立全局设计变量。
4. 使用 `batch_design` 分批创建画板和组件，每批控制在工具允许的操作数量内。
5. 每完成一组页面后调用 `get_screenshot`，与 HTML 原型和参考材料对照检查。
6. 优先修正整体布局和尺寸，再修正字体、间距、颜色、图标和细节状态。
7. 全部确认后调用 `export_nodes`，将 PNG 导出到当前需求的 `原型截图/` 目录。
